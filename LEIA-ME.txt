=====================================
COFFEE PDV - QUICK START GUIDE
=====================================

Você tem 3 scripts prontos para usar:

1. START_DOCKER.bat
   - Inicia todos os containers (app + MySQL + RabbitMQ)
   - Clique 2x ou execute no terminal

2. VIEW_LOGS.bat
   - Mostra os logs dos containers
   - Execute para ver o que está acontecendo

3. STOP_DOCKER.bat
   - Para todos os containers
   - Execute quando quiser parar

=====================================
COMO USAR:
=====================================

1. Abra D:\workSpace\coffee

2. Clique 2x em START_DOCKER.bat
   Aguarde ~30 segundos até aparecer "Docker containers started successfully!"

3. Abra seu navegador:
   http://localhost:8080

4. Você verá a aplicação Spring Boot rodando!

5. Para ver os logs:
   Clique 2x em VIEW_LOGS.bat

6. Para parar:
   Clique 2x em STOP_DOCKER.bat

=====================================
TROUBLESHOOTING:
=====================================

Se der erro "port already in use":
  - Abra Task Manager
  - Procure por "docker" ou "mysql"
  - Encerre ou mude as portas em docker-compose.yml

Se o container não inicia:
  - Execute VIEW_LOGS.bat para ver a mensagem de erro
  - Verifique se o arquivo .env.docker existe
  - Tente STOP_DOCKER.bat e depois START_DOCKER.bat novamente
